DVWA Web Application Penetration Testing

Cybersecurity Web Application

Overview

This project explores web application security using Damn Vulnerable Web Application (DVWA) in a controlled environment. It includes identifying and exploiting common vulnerabilities such as SQL injection, cross-site scripting (XSS), and insecure authentication mechanisms. The project demonstrates a structured approach to vulnerability testing and highlights mitigation techniques and secure development practices.

Objective

The objective of this project was to gain practical experience in identifying and exploiting common web application vulnerabilities. It also aimed to develop a structured approach to penetration testing and understand how insecure coding practices can lead to real-world security risks.

Environment Setup

The project was conducted in a controlled local environment to ensure safe and ethical testing. DVWA was deployed on a local server using a virtual machine environment.

- Platform: Local VM environment
- Operating System: Kali Linux
- Tools Used: Web browser, Burp Suite
- DVWA Security Level: Tested across low to medium levels

This setup allowed for safe experimentation and realistic simulation of web security testing scenarios.
