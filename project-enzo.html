Overview

Enzo Wongpradu is a locally hosted AI assistant designed for personal and family use. It runs on a local Ollama model and supports both terminal and browser interfaces through a shared agent architecture.

The system can manage workspace files, check installed software, run approved development commands, install trusted software, and search for current information online. Sensitive actions such as writing files, running commands, or installing software require explicit approval.

Enzo also includes user authentication, separate conversation history, role-based access control, mobile support, and administrator-only computer tools.

Tech Stack

- TypeScript
- Node.js
- Express.js
- Ollama
- Qwen3 8B
- Serper API
- HTML, CSS, JavaScript
- REST APIs
- JSON-based data storage
- Git and GitHub
- Windows PowerShell
- Tailscale for private remote access
