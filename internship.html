Cybersecurity Analyst Intern

Cybertron | June 2025 - Aug 2025

Overview

This internship involved hands-on experience in cybersecurity operations, focusing on network traffic analysis, vulnerability assessment, and basic incident response. Work included monitoring system activity, identifying potential security threats, and analyzing suspicious behavior using industry-standard tools. The experience provided practical exposure to real-world security workflows and strengthened understanding of how organizations detect, investigate, and respond to security incidents.

Tools & Technologies

Splunk, Trelix, Arbour, Palo Alto, WAF, CWAF

Responsibilities

  • Monitored client environments during 12-hour shifts, analyzing security alerts and identifying potential threats
  • Investigated multiple security incidents, distinguishing between false positives and genuine threats
  • Performed basic incident response actions, including isolating affected machines and blocking malicious IP addresses
  • Monitored and responded to network-based attacks, including DDoS activity, using security tools
  • Collaborated with threat intelligence efforts by reviewing emerging threats related to regional cybersecurity events
  • Communicated directly with clients to provide updates, clarify incidents, and support security operations
  • Prepared and documented daily security reports summarizing alerts, investigations, and response actions
  • Utilized enterprise security tools to monitor system activity and maintain overall security posture
