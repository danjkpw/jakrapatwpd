Diabetes Prediction Model

Machine Learning Data Science

Overview

This project implements a machine learning-based diabetes prediction system using the Pima Indians Diabetes dataset. Multiple models, including Logistic Regression, Random Forest, and XGBoost, were trained and compared to evaluate their performance. After selecting the most suitable model based on accuracy and evaluation metrics, a terminal-based application was developed to accept user health inputs such as age and other medical indicators, and predict the likelihood of diabetes. The project demonstrates practical experience in model comparison, evaluation, and deploying a simple predictive system.

Tech Stack

Python, Logistic Regression Model, Google Colab, Random Forest Model, XGBoost Model

How It Works

The terminla based demo accepts user inputs for various health indicators and uses the trained machine learning model to predict the likelihood of diabetes, providing insights based on the input data.
