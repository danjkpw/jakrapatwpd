Real Time Object Detection Model for Waste Sorting

Overview

This project presents an intelligent waste sorting system that uses a YOLOv11s object detection model to classify different types of waste in real time. The model is deployed on a Jetson Orin Nano, enabling edge-based processing for fast and efficient detection without relying on cloud services. Based on the detected object, the system controls mechanical lids using servo motors to automatically sort waste into the appropriate categories. This integration of computer vision and embedded hardware demonstrates a practical approach to automating waste management and improving sorting efficiency.

Tech Stack

Python, YOLO, Jetson Orin Nano OBC, Google Colab

How It Works

The camera detects objects in real-time and sends signals to servos to sort waste into appropriate bins.
