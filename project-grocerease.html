Grocery Store Management System

Overview

Grocerease is a web-based grocery store management system designed to handle core business operations such as inventory tracking, employee management, and user account handling. The application was built using HTML and CSS for the frontend, with a PHP backend connected to a MySQL database for data storage and processing. In addition to functionality, the project incorporates basic cybersecurity practices. Passwords are securely stored using hashing techniques, and prepared statements are implemented in PHP to prevent SQL injection attacks. This demonstrates an understanding of both application development and secure coding principles.

Tech Stack

HTML/CSS, PHP, MySQL Database
